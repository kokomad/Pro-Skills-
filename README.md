# Skills Hub — مركز مهارات Claude Code

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا وارفع الملفات الأربعة: `index.html` `manifest.json` `sw.js` `icon.svg`
2. Settings ← Pages ← Source: `main` / root ← Save
3. افتح `https://USERNAME.github.io/REPO/` ثم من متصفح الجوال اختر "إضافة إلى الشاشة الرئيسية"

## تعديل المهارات
افتح `index.html` وعدّل المصفوفة `SKILLS` (اسم، تصنيف، أوامر). أكّد الأوامر من الصفحات الرسمية للمهارات.
